# My Daily Planner — by Romalite Life

A personalized daily planner built for individuals with Down syndrome and their families.
Designed to be joyful, accessible, and easy to use every single day.

## Features
- Personalized greeting with your name
- Morning routine checklist with progress tracker
- Activity picker with 125+ activities across 10+ categories
- Text-to-Speech — reads the whole day out loud
- Joy Log — save happy moments every evening
- Daily affirmations
- Weekly view with ability to plan future dates
- Works 100% offline — no internet needed after first load
- Installable as a phone app (Add to Home Screen)
- 6 color themes including Romalite Yellow, adjustable text size, voice speed control

## What "Installable PWA" Means
PWA = Progressive Web App. It means this app lives on a website but **installs and works exactly like a real app** on any phone or tablet:
- No App Store required
- No download required
- Works 100% offline after first visit
- Gets its own icon on the home screen
- Opens full screen with no browser bar — looks and feels like a native app
- Saves all data privately on the device (nothing sent to any server)

**On iPhone:** Open the link in Safari → tap the Share button → tap "Add to Home Screen"
**On Android:** Open the link in Chrome → tap the 3-dot menu → tap "Add to Home Screen" or "Install App"


1. Wait 1-2 minutes → your link will appear:  https://romalitetools.github.io/daily-planner/`

That link is the shareable URL. Send it to anyone — they can install it on their phone from that link.


## Files in This Package
| File | What it does |
|------|-------------|
| `index.html` | The entire app — all code, all features, one file |
| `manifest.json` | Tells the phone how to install it (name, icon, colors) |
| `sw.js` | Service worker — makes it work offline |

All three files must be uploaded together for the app to work properly.
